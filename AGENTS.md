**## Interface design**

**- Use shadcn/ui and the components already in the project when building or changing interfaces.**

**- Before designing a screen, consult `docs/design-system.md` and the design tokens in `src/app/globals.css`.**

**- Use the project’s semantic color tokens. Avoid adding arbitrary colors when an existing token fits.**

**- Keep typography, spacing, corner radii, interaction states, and responsive behavior consistent.**

**- Don’t replace existing components with different patterns without a clear reason.**

**- If a needed rule or token is missing, propose a consistent addition and document it.**
